## 1. 设备是什么

| 项目 | 内容 |
|---|---|
| 厂商/系列 | 普源精电 RIGOL DG800 系列 |
| 型号 DG832 | **双通道** 函数/任意波形发生器，最大输出频率 **35 MHz** |
| 采样率 / 分辨率 | 125 MSa/s，16 bit |
| 屏幕 | 4.3 英寸 TFT 彩色**触摸屏** |

## 2. 快速上手（第一次使用）

1. **开机**：接好电源线 → 按前面板电源键 → 仪器自检后进入默认界面。
2. **设置中文**：按 `Utility` → 触摸点「系统设置」→ 点 `Language` 右侧选择框 → 选中文。
3. **看设备信息**：`Utility` → 「系统信息」（型号、序列号、软件版本号）。

### 实例：从 CH1 输出一个正弦波（20 kHz / 2.5 Vpp / 500 mVdc 偏移 / 90° 相位）

1. 按 `Output1` 选中 CH1 通道（状态栏中该通道变红色）。
2. 按 `Menu` → 触摸点 `Continuous` → 点 **Sine** 图标，进入正弦波参数界面。
3. 频率：点「频率」右侧输入框 → 数字键盘输 `20` → 单位选 `kHz` → `Ok`。
4. 幅度：输 `2.5` → 单位 `Vpp` → `Ok`。
5. 偏移：输 `500` → 单位 `mVdc` → `Ok`。
6. 相位：输 `90` → 单位 `°` → `Ok`。
7. 再按 `Output1` 使能输出（按键背灯点亮、通道状态条高亮），[CH1] 连接器即输出信号。
8. 用 BNC 线接示波器观察波形。

> 操作通用写法：`按键 → 菜单标签 → 参数输入框`。双通道型号 CH2 操作与 CH1 相同。

## 3. 面板与接口

### 前面板
| 键/区 | 作用 |
|---|---|
| 电源键 | 开关机 |
| `Output1` / `Output2` | 通道输出开关（背灯亮 = 输出中） |
| `Menu` | 波形选择界面 |
| `Home` | 返回主页 |
| 功能键区 | Utility / Store / 频率计等 |
| 方向键 + 旋钮 | 选中与调节参数 |
| `Help/Local` | 内置帮助；**退出远程控制模式**（远程时前面板被锁定） |
| [Counter] 输入口 + 频率计 | 测外部信号频率（240 MHz / 7 digits/s） |

### 后面板
| 接口 | 用途 |
|---|---|
| **USB DEVICE** | 连电脑（远程控制，USB-TMC）—— **就是你现在用的这个** |
| USB HOST | 插 U 盘（存波形/配置文件，需 FAT32 Flash 型）或 USB-LAN/USB-GPIB 扩展模块 |
| 10MHz In/Out | 外部 10 MHz 参考时钟输入/输出 |
| CH1/CH2 同步/外调制/触发 | 同步、外调制、触发输入 |
| AC 电源插口 | 100-240 V 自适应，最大 30 W |

## 4. USB 连接与驱动安装（解决"没驱动"）

**你的现状**：USB 线连上后，信号源屏幕有 USB 已连接显示（设备侧正常），但电脑端设备管理器里是"未知设备"——缺驱动。

**手册要求安装的驱动**：`USB Test and Measurement Device (IVI)`（USB-TMC 类仪器标准驱动）。
**这个驱动来自 RIGOL 官方软件 Ultra Sigma（自带 NI-VISA 库，装完驱动即自动就绪）**。

步骤：

1. **下载 Ultra Sigma**：登录 RIGOL 官网 `www.rigol.com` → 产品 → 找到 DG800 系列（或任意示波器/信号源产品页）→ 「软件&固件 / Software&Firmware」→ 下载 **Ultra Sigma 软件安装包**（几百 MB）。安装包通常也会在随机的光盘/U 盘里。
2. **安装**：解压后运行 Setup 按提示安装（会一并装上 NI-VISA 运行库）。
3. **装驱动**：安装完成后，把 USB 线**重新插拔一次**；若设备管理器里仍是"未知设备"，右键 →「更新驱动程序」→「浏览我的电脑」→ 手动指向 Ultra Sigma 安装目录（常见 `C:\Program Files\RIGOL\Ultra Sigma\` 下的驱动文件夹，或 `C:\Program Files\IVI Foundation\VISA\`）。
4. **验证**：设备管理器应出现 `USB Test and Measurement Device (IVI)` 或 Rigol 设备；打开 Ultra Sigma，软件自动搜索到资源，例如：
   `DG832 (USB0::0x1AB1::0x0642::DG80000000001::INSTR)`
5. **通讯测试**：右键该资源名 → `SCPI Panel Control` → 发一条命令（如 `*IDN?`）能回设备型号即成功。

> 备选方案：单独安装 NI 的 **NI-VISA**（ni.com 下载）也能提供同样的 USB-TMC 驱动。

### ⚠️ 必须安装「完整版 NI-VISA」（重要教训）

只装 Ultra Sigma（自带旧版 IVI visa 3.2）**不够**。实测本机旧版 `C:\Windows\System32\visa32.dll`（版本 3.2.0.16416）的 USB-TMC 实现有缺陷：
- 现象：连接后**第一条命令能通，第二条命令起报 `VI_ERROR_TMO` / `VI_ERROR_IO`**，设备 USB 状态机卡死；拔插 USB 只能短暂恢复一条命令。
- 解决：安装**完整版 NI-VISA**（winget: `NI.ni-visa`，或 ni.com 下载）。本机安装 26.3 后 `visa64.dll` 升级为 **8.0.7331**，问题彻底消失，连续查询稳定。
- 验证方式：`(Get-Item C:\Windows\System32\visa64.dll).VersionInfo.FileVersion` 应为 5.x/8.x，而不是 3.2.0。

### 在设备上查看 USB 身份信息
按 `Utility` → 「接口设置」→ `USB`，界面上部显示 **USB ID**（VISA 描述符的一部分，如 `USB0::0x1AB1::0x0642::…`）。

## 5. 远程控制（SCPI）

- 连接方式：USB（USB DEVICE 口，直连）／LAN（USB-LAN 模块）／GPIB（USB-GPIB 模块）。
- 命令协议：SCPI，基于 **NI-VISA** 库（编程手册附录有 Excel / MATLAB / LabVIEW / VB / VC++ 完整示例）。
- MATLAB 示例（摘自编程手册）：

```matlab
DG800 = visa('ni','USB0::0x1AB1::0x0642::DG80000000001::INSTR'); % 创建 VISA 对象
fopen(DG800);   % 打开连接
fprintf(DG800, '*IDN?');  % 查询设备标识
disp(fscanf(DG800));      % 读返回
fclose(DG800);  % 关闭
```

- 常用 SCPI 示例：`*IDN?`（查 ID）、`:OUTP1 ON`（开 CH1 输出）、`:SOUR1:FREQ 1e3`（设频率 1 kHz）、`:SOUR1:VOLT 2`（设幅度 2 Vpp）。
- 注意：进入远程控制后，前面板与触摸屏被锁定（电源键、`Help/Local` 除外），按 `Help/Local` 可退出远程模式回到本地。

## 6. 常见问题（摘自手册第 4 章）

| 现象 | 处理 |
|---|---|
| 无波形输出 | 检查 BNC 线连接；`Output1/2` 背灯是否点亮；必要时 `Utility→系统设置→上电值` 设为「上次值」重启 |
| 屏幕太暗 | `Utility → 显示设置 → 亮度` 调大 |
| 面板被锁定 | 处于远程模式，按 `Help/Local` 退出 |
| U 盘不识别 | 用 FAT32 格式 Flash 型 U 盘（不支持硬盘型），重插/重启仪器 |
| 幅度不能用 dBm | 通道设置里「输出设置→高阻」需关闭，再设置负载值后才能用 dBm 单位 |
