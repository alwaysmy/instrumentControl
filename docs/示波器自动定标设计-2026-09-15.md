# 示波器"通道自动定标/居中"设计（2026-09-15）

> 需求来源：用户提问——**"让波形合适居中能否自动化判别？（类似 auto，但只设置指定通道的垂直挡位）"**
> 背景：2026-09-15 模拟输出量程排查中，为了把波形放到合适档位/居中，反复手调 `SCALe`/`OFFSet`，
> 踩了一串坑（中心=−offset、改档位等比缩放偏置、通道关闭时写入被忽略、超屏读数返回 9.9E37 甚至假值）。
> 结论：**可以自动化，且判据是可测的**；本文给出判据、有界搜索算法、边界情形与验证方法。

---

## 1. "合适居中"必须先定义成可测的判据

否则无法自动化。三条判据都能用现有 SCPI 直接测：

| 判据 | 定义 | 测法 |
| ---- | ---- | ---- |
| ① **可测性** | 测量引擎能给出有效值 | `:MEASure:ITEM? VPP/VMAX/VMIN,CHANnel<n>` 不返回 `9.9E37` |
| ② **不贴边** | 极值离窗口上下沿有裕量 | `VMAX < W_top − margin·H` 且 `VMIN > W_bot + margin·H`（`margin≈0.08~0.10`）|
| ③ **占屏率合适** | 波形占窗口高度的比例在带内 | `occupancy = VPP / H ∈ [0.4, 0.9]`，目标 0.6~0.8 |

其中窗口（**本机实测标定**，垂直 8 格）：

```
H   = 8 × scale
W_top = −offset + 4 × scale
W_bot = −offset − 4 × scale
```

**②是最关键的一条**：只查①会被骗——部分削顶时测量引擎给的是"**看着合理的假值**"
（本项目曾读到 0.9216 V，而真实信号 ±10 V）。图元贴边即说明该值不可信，必须重新选档。

---

## 2. 算法：有界放大搜索 + 定标 + 验证

```
fit_channel(ch, occupancy=0.7, margin=0.08, max_iter=12):
  S0 前置
     - 通道必须处于 ON：**通道关闭时写 SCALe/OFFSet 会被静默忽略**（无错误码）→ 直接判错并提示先开
     - 快照 scale / offset / probe；读回确认（写入可能被设备钳制）
  S1 可测性搜索（只在"读数无效"时执行）
     - 当前档不可测 → 沿 1-2-5 序列**逐档放大**（放大 = 窗口变宽），重测
     - 到最大档仍不可测 → 返回 "信号超出可测范围/无信号"，附逐档原始响应作为证据
  S2 贴边修正（判据②）
     - 若 VMAX 或 VMIN 落在边距带内 → 再放大一档后重测
     - 与 S1 合并为同一个循环，共用迭代上限
  S3 计算目标档位
     - span = VMAX − VMIN
     - if span < 噪声底（如 < 3×该档 LSB）→ 判为**平直/无信号**，返回特殊状态，
       **不猜档位**（猜了就是假精度）；需要时由调用方显式给档
     - scale_target = snap_1_2_5( span / (occupancy × 8) )    ← 必须吸附到设备允许的档位序列
     - offset_target = −(VMAX + VMIN) / 2                      ← 中心电压 = −offset
  S4 应用与回读
     - **先写 SCALe，后写 OFFSet**（设备会按新档位等比缩放旧 offset，先写 offset 必错）
     - 两个都回读；与目标不符时以回读值为准重算（设备可能钳制到自己的档位表/偏置量程）
  S5 验证（判据①②③重测）
     - 达标 → 返回；不达标 → 回 S2，最多 max_iter 次
     - 若失败原因是 **偏置超量程**（如本机 ±20 V）→ 明确报
       "该档位无法置中（可设范围 ±X），建议 scale ≥ Y"，**不要假装成功**
```

- 迭代次数：1-2-5 序列从最小到最大约 10 档 → `max_iter=12` 足够；LAN 上每次测量 ~20–50 ms，
  整轮定标**亚秒级**。
- `snap_1_2_5`：把目标值吸附到 `{1,2,5}×10ⁿ`；设备自身也会钳制，故以回读为准。

## 3. 返回体（关键：把"判断依据"一起返回，而不只是 ok）

```json
{ "ch": 3, "ok": true,
  "before": {"scale": 0.5, "offset": -1.75},
  "after":  {"scale": 2.0, "offset": -3.5},
  "measured": {"vmax": 7.4825, "vmin": 7.4748, "vpp": 0.0077},
  "occupancy": 0.001, "margin_ok": true,
  "note": "flat/DC signal: scale kept at requested value, centered by mean",
  "warnings": ["probe=10X → values are tip volts"] }
```

失败时必须带 `reason` + 证据（逐档测量响应原文），便于人一眼判断是"信号问题"还是"档位问题"。

## 4. 明确不能自动的部分（诚实边界）

| 情形 | 工具能做到 | 做不到 |
| ---- | ---------- | ------ |
| 信号完全离屏且远大于最大档 | 逐档放大到顶后报"超出可测范围" | 给出真实幅度（**没有任何读数能恢复被 ADC 削掉的信息**）|
| 部分削顶 | 靠判据②识别"读数不可信"并放大 | 用一次读数直接给出真实 VPP |
| 交流耦合 | 在 AC 域内居中 | 还原被耦合电容剥掉的直流分量 |
| 平直/无信号 | 判为平直并**不猜档位** | 自动选一个"好看"的档位 |
| 探头比 | 原样读回并提示口径 | 判断物理上接的是不是 10X 探头 |

> 一句话：**工具能保证"读数可信 + 不贴边 + 占屏合适"，不能保证"测到真实幅度"**——
> 后者在信号超出量程时物理上不可能。

## 5. 与既有工具/代码的关系

- 现状：MHO 侧只有 `mho_status / measure_item / screenshot / get_waveform / acquisition / autoset`，
  **没有任何垂直档位/偏置的设置工具**（只能用 `instr_write` 裸 SCPI）。本工具应作为
  `mho_channel(ch, scale?, offset?)` 之后的**上层封装**：
  - 底层复用库里的 `rigol_scope.channel_scale/channel_offset`（已实现，只差 MCP 包装）
  - 判据/搜索逻辑放在 `mho_control`（或 `rigol_scope`）里做纯函数，便于单测
- **家族常量**：垂直格数与"中心=−offset"约定按 family 配置（RIGOL MHO984D 实测 8 格；
  SDS 需实测标定后再填，**不要照抄**）。
- 与 `autoset` 的区别（也是存在的理由）：`autoset` 是**全局破坏性**的（动所有通道/时基/触发）；
  本工具**只动指定通道的 scale/offset**，且**每步可回读、可解释、可回退**。
- 时间轴不在职责内；但建议在返回里附一条**边沿数检查**（屏内 <2 个边沿时不能测频率，
  本次实测：20 µs/div 看 5 kHz 读不到，100 µs/div 立刻 4.9995 kHz），提示调用方。

## 6. 验证用例（用本次踩过的真实场景做回归）

| # | 场景 | 期望 |
| - | ---- | ---- |
| 1 | 7.48 V 直流，当前 2 V/div、offset −3.5 | 判为平直 → 保持档位、按均值居中 → occupancy 记为平直，不报错 |
| 2 | 同上但档位被设成 0.5 V/div（信号离屏） | S1 逐档放大到可测 → 定标到可容纳的档位 ✓ |
| 3 | 信号被端子 TVS 钳在 7.3 V（真实想输出 10.4 V） | 工具**不应报错**——它测到的是物理真相（7.3 V）；但要保证不贴边、可测 ✓ |
| 4 | 报警时端子变数字电平 3.27 V | 正常定标（幅度变化不影响流程）|
| 5 | 平直 0 V（无信号） | 返回"平直/无信号"，**不猜档位** |
| 6 | 通道 OFF 时调用 | 明确报错并提示先开通道（**不静默无功而返**）|
| 7 | 需要 offset 超出 ±20 V 才能置中 | 报"该档位无法置中" + 建议 scale，不静默失败 |

---

## 7. 一句话摘要

**能自动化**：把"合适"落成 **可测性 / 不贴边 / 占屏率** 三条判据，用**有界放大搜索**找可测档位，
按 `scale = span/(occupancy×格数)`、`offset = −中心` 定标，**先 scale 后 offset** 并回读验证。
风险点是"读数在削顶时会说谎"，靠**贴边判据**兜住；物理上无法恢复的信息（超出量程的真实幅度）明确报出来，不装。
