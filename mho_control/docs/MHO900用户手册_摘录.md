## 1. 型号与型号间规格差异

### 1.1 型号列表与带宽（用户手册唯一的分型号规格表）

出处：**物理 p.27（印刷 p.9）**，第 3 章「文档概述」→「文档内容的约定」。
原文：“MHO900 系列数字示波器包含以下型号。如无特殊说明，本手册以MHO984 为例说明MHO900 系列示波器基本操作。”

| 型号 | 最大模拟带宽 | 模拟通道数 |
|---|---|---|
| **MHO984** | 800 MHz（单通道<sup>[1]</sup>&半通道<sup>[2]</sup>）<br>400 MHz（全通道<sup>[3]</sup>） | 4 |
| **MHO954** | 500 MHz（单通道<sup>[1]</sup>&半通道<sup>[2]</sup>）<br>400 MHz（全通道<sup>[3]</sup>） | 4 |
| **MHO934** | 350 MHz（任意通道数） | 4 |

通道模式定义（同页原文注释，**驱动判带宽时必须理解**）：
- `[1]` **单通道模式**：任意开启一个通道。
- `[2]` **半通道模式**：任意开启两个通道。
- `[3]` **全通道模式**：任意开启三个通道或开启全部通道。

> **关键含义**：MHO984/MHO954 的标称带宽（800/500 MHz）**只在开启 ≤2 个通道时成立**；一旦开启 3 或 4 个通道，带宽降为 400 MHz。MHO934 无此限制。

## 3. 远程控制（第 25 章）

**章节位置：物理 p.263–p.264（印刷 p.245–p.246）。全章仅 2 页。**

出处原文（p.263 / 印刷 p.245）：“远程控制本仪器主要有以下方式：”

### 3.1 方式一：用户自定义编程（SCPI）

原文：“用户可以通过标准 SCPI（Standard Commands for Programmable Instruments）命令对仪器进行编程控制。有关命令和编程的详细说明请参考本系列产品的《编程手册》。”

→ **用户手册本身不列出任何命令、端口号或协议细节，全部指向《编程手册》。**

### 3.2 方式二：Web Control 远程控制

原文：“本产品支持 Web Control 远程控制功能。示波器的 Web Control 功能是一种基于浏览器（Web）的远程控制技术，允许用户通过网络远程访问和操控仪器，无需额外安装软件。通过Web 浏览器远程访问已联网的仪器，控制端（包括 PC 端、手机端和 iPad 等智能端）网页将实时显示仪器的用户界面，用户可通过控制端查看设备信息，调整仪器的时基、垂直灵敏度，设置触发条件等。具体操作步骤如下：”

1. **仪器连接网络** — 原文：“确保仪器后面板的LAN 接口连接至网络。注意仪器必须连接到与控制端所在相同网域的网络，并通过该网络进行访问才可进行远程操控。”
2. **获取仪器 IP 地址** — 原文：“点击仪器左下角的功能导航图标 > 辅助，进入辅助菜单，在基本设置栏中查看仪器IP 地址。”
3. **在浏览器URL 行输入仪器的IP 地址**，按 Enter。
4. 点击左侧 **Web Control** 进入仪器控制界面，实时远程控制，原文“效果与在仪器屏幕上直接进行触控操作基本一致”。
5. 点击 **Print Screen** 可选择 **Take Screenshot（截图）** 或 **Record Screen（录屏）**。
6. 点击左侧 **Network Settings** 可更改网络配置；原文：“注意更改网络配置时需要登录，**首次登录 Web Control 的用户名和密码分别为“admin”和“rigol”**。”
7. **SCPI Panel Control** — 原文：“SCPI Panel Control 功能支持用户通过Web 界面直接发送SCPI 指令，实现对仪器的远程编程控制。点击 SCPI Panel Control，在SCPI Command 输入框中输入指令，输入完成后点击 **Send&Read** 按键，便可控制仪器。有关命令和编程的详细说明请参考本系列产品的《编程手册》。”
8. 原文：“关闭浏览器可退出仪器远程控制界面。”

**并发限制（原文）**：“仪器IP 地址仅允许一名用户登录进行远程登录控制，不支持多人同时登录。若出现连接中断现象，可刷新浏览器重新加载此页面。”
**注意（原文）**：“连接通信电缆之前，请将仪器关机，以免损坏仪器的通信接口。”

### 3.3 网络配置细节（第 24 章 系统功能设置 → 24.1 接口设置）

出处：**物理 p.254–p.256（印刷 p.236–p.238）**。

- **网络状态**可能提示：`Network Config Succeeded!`、`Acquiring IP...`、`IP Conflict!`、`DISCONNECTED`、`DHCP Config Failed`、`Read Status Fail!`、`CONNECTED`、`Invalid IP`、`IP lose`、`Please wait...`
- **MAC 地址**：唯一，用于分配 IP。
- **VISA 地址**：原文“显示仪器当前使用的VISA 地址。” → 仪器界面直接可读 VISA 资源串（**驱动可据此连接**）。
- **IP 配置方式**：动态 IP / 自动 IP / 静态 IP。
  - **动态 IP**：由 DHCP 服务器分配 IP、子网掩码、网关、DNS。
  - **自动 IP**：原文“设备根据当前网络配置自动获取从 **169.254.0.1 至 169.254.255.254** 的IP 地址和子网掩码 **255.255.0.0**。当“动态IP”未选中或者连接失败时，“自动IP”才起作用。”
  - **静态 IP**：需手动配置 IP、子网掩码、网关、DNS。IP 格式 `nnn.nnn.nnn.nnn`，第一段 0~255（127 除外），**有效范围 0 至 223**，其余三段 0~255。设置保存在非易失性存储器中（配合“加载上次值”=“上次值”）。
  - **优先级（原文）**：“三种IP 配置类型均打开时，参数配置的优先级从高到低依次为“动态IP”、“自动IP”、“静态IP”。”；“三种IP 配置类型不能同时关闭。”
- **mDNS**：原文“通过mDNS 项的功能键，可启用（ON）或禁用（OFF）多播域名系统（mDNS）。该系统在没有DNS 服务器的小型网络中为服务探索提供DNS 服务器的功能。”
- **主机名**：原文“主机名称支持输入最大为 **26 个字节**长度的字符串。”
- **应用**：点击“应用”后网络参数生效。
- 出厂默认主机名格式（如 `mho9xxxxxxxx.local` 之类）→ **未找到**。
- 所支持的网络服务端口号（5025 / 111 / VXI-11 / HiSLIP 等）→ **未找到**（全 279 页检索 `VXI`、`HiSLIP`、`5025`、`套接字`、`端口` 均未命中相关说明）。

### 4.3 采样系统（第 7 章，物理 p.66–p.72 / 印刷 p.48–p.54）

#### 4.3.1 获取方式（Acquisition Type）—— 4 种

出处：**物理 p.66–p.67（印刷 p.48–p.49）**。原文：“可在 获取方式 项中选择 **普通、平均、峰值或高分辨率**，默认获取方式为普通。”

| 获取方式 | 原文要点 |
|---|---|
| **普通（Norm）** | 按相等时间间隔采样重建波形，大多数波形最佳显示效果 |
| **平均（Avg）** | 对多次采样波形平均，减少随机噪声、提高垂直分辨率。**平均次数取值范围 2 ~ 65536，默认值 2**。原文提示：“平均次数必须是2 的N 次方。当输入数值不为2 的N 次方数时，示波器屏幕会弹出“平均次数截断”提示，此时平均次数会自动设置为小于输入数值且最近的2 的N 次方。” |
| **峰值（Peak）** | 采集采样间隔内信号的最大值和最小值，获取包络或窄脉冲，避免混叠。原文：“该模式下，最小检测脉宽为采样周期。” |
| **高分辨率（HiRes）** | 超取样技术，对邻近点平均。可选 **比特数 14 或 16，默认值 14**；原文“框后显示所选位数对应的带宽”。提示：“在高分辨率模式下，示波器以牺牲带宽来换取测量精度的提高。” |
